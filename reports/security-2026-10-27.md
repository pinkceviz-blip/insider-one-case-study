# Frontend / SQL injection incelemesi · 27 Ekim 2026

## Sonuç

- `make test`: PASS (Go `-race`, gerçek PostgreSQL/Redis, Vue güvenlik testleri, production build).
- Go paketi: 32.891 saniye; race detector ihlali görülmedi.
- Vue/Vitest/jsdom: 12/12 test geçti.
- `npm audit`: 0 low/moderate/high/critical, toplam bilinen açık 0. Bu, registry'nin o andaki advisory verisine göredir; açık bulunmadığı garantisi değildir.
- Uygulamanın incelenen SQL yollarında kullanıcı değerleri parametreyle bağlanıyor; test edilen payload'lar SQL olarak yürütülmedi. HTTP hata yanıtlarında DB sorgusu/bağlantı bilgisi görülmedi.

## Eklenen / doğrulanan kontroller

1. Frontend ve backend campaign/delivery ID biçim allowlist'i; URL bileşenlerinin güvenli oluşturulması. Müdahale edilmiş localStorage kampanya kimliği temizlenir.
2. Backend kanal/hata sınıfı/cursor doğrulaması; SQL görünümlü ID ve filtreler 400 ile reddedilir.
3. O'Reilly, apostrof, SQL anahtar kelimeleri içeren brief ve mesajlar bozulmadan veri olarak saklanır. Keyword blacklist/manuel SQL escaping eklenmedi; mevcut parametreli sorgular korundu.
4. Boolean (`OR 1=1`), UNION SELECT, DROP/UPDATE ve pg_sleep payload'ları HTTP üzerinden gönderildi; kullanıcı tablosu ve ilgisiz kampanya korunuyor. ID saldırıları DB sorgusuna ulaşmadan reddedilir; metin alanındaki SQL benzeri içerik parametre olarak kalır.
5. Saklanan kampanya brief'i, SSE'den gelen SMS ve API hata mesajları `<img onerror>` / `<script>` içerse bile Vue test DOM'unda img/script elemanına dönüşmedi.
6. Bilinmeyen template değişkeni frontend'de kaydetmeyi engeller; backend aynı iş kuralını bağımsız doğrular.
7. Cross-origin POST 403; same-origin yazma geçer. Nginx API upstream'ine gerçek Host'u taşır. Bu Origin kontrolü auth/RBAC yerine geçmez.
8. Nginx CSP: script-src self, object-src none, base-uri none, frame-ancestors none, form-action self; X-Frame-Options DENY, nosniff ve Permissions-Policy eklendi. İlerleme çubuğu gibi uygulama stilleri için yalnız style-src-attr inline izni var; inline script izni yok.

## Sınırlar

Frontend testleri Vitest/jsdom bileşen testidir; bağımsız gerçek tarayıcı pentesti değildir. Canlı Nginx başlıkları ayrıca doğrulandı: CSP, DENY, nosniff ve Permissions-Policy mevcut. Canlı proxy üzerinden yabancı Origin POST 403, aynı Origin POST 202 döndü. Ayrıntılar security-live-smoke-2026-10-27.json içinde. Statik/manual inceleme ve seçilmiş regresyon payload'ları tüm SQLi/XSS varyantlarını kanıtlamaz. Auth, tenant izolasyonu, üretim TLS/secret yönetimi ve kapsamlı yük testi önceki case kapsamı dışında kalır. Gerçek Claude veya gerçek SMS/email servisi çağrılmadı.
